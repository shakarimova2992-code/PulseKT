# Kazakhtelecom HUB

Готовый статический сайт для GitHub Pages.

## Файлы
- `index.html` — страница сайта
- `style.css` — весь дизайн
- `script.js` — анимация светящихся точек и лёгкий parallax

## Загрузка на GitHub
1. Открой репозиторий.
2. Удали старые файлы `index.html`, `style.css`, `script.js`, если они там есть.
3. Загрузить эти три файла **в корень репозитория**.
4. В GitHub открой Settings → Pages и выбери Deploy from branch → `main` → `/ (root)`.
